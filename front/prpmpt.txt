en la carpeta back está el backend del proyecto. En la carpeta back/models están los modelos de Base de Datos y en index.js las relaciones entre estos. Necesito que en delivery_controller.js se edite el método getDeliveriesByUserName. Se le debe pasar el id del usuario como parámetro. En caso de que este usuario este tenga rol "dealer" , se deben devolver las entregas (o deliveries) asociadas al id del usuario pasado como parámetro (en el modelo, el id de este usario corresponde a dealer_user_id). Si el usuario que se pasó como parámetro tiene rol "reader" se deben devolver las entregas correspondientes al id del usuario pasado como parámetro (por medio de los préstamos o loans, donde reader_user_id corresponde al id de dicho usuario). También modifica su respectiva ruta en delivery_routes.js
